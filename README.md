# Hisaab

An offline, Android-first personal finance diary: income, expenses, receipts, budgets, and a simple udhaar (money given to / taken from friends) tracker. No login, no server, no cloud — all data stays on the phone.

Built with Expo SDK 58, React Native, TypeScript, and Expo Router.

- Specs (source of truth): [docs/README.md](docs/README.md)
- Current status and decisions: [docs/PROJECT_CONTEXT.md](docs/PROJECT_CONTEXT.md)
- Setup on Windows: [docs/09-config/ENVIRONMENT_SETUP.md](docs/09-config/ENVIRONMENT_SETUP.md)

```
npm install
npm run typecheck
npm run lint
npm test
npm run android   # needs Android Studio + a device or emulator
```
