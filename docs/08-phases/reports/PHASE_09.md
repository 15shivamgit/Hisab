# Phase Report — Phase 9: Settings, app lock, onboarding, polish

Date: 2026-10-29 · Branch: `main`

**Status: acceptance criteria verified on the owner's phone (exceptions in § 5) — awaiting owner approval.**

## 1. What was implemented

- **Settings (SET-01, SET-03, SET-04, SET-05):**
  - `SettingsProvider` reads all settings in one query and pushes `theme` into `ThemeProvider`. Before Phase 9 the theme setting existed but was never applied; the app always followed the system.
  - `settingsService`: portable settings (theme, week start, reminders) mark data as changed since the last backup; device-only settings (app lock, lock timeout, onboarding) do not. Reminder and app lock changes re-plan reminders.
  - More tab: Manage · Data · **Preferences** (theme, week start, udhaar reminders switch + time picker, "Open settings" if notifications are denied) · **Security** (app lock, Lock after) · **About** · Danger zone.
- **App lock (SET-02, ADR-011, ADR-016):**
  - `LockGate` sits between `SettingsProvider` and the navigator:
    - Cold start with lock on: nothing below it mounts, so no data is queried until unlock.
    - Later locks: a full-screen `Modal` over the mounted screens, so unsaved form input survives. It also covers open sheets.
    - "Immediately": the cover goes up as the app leaves.
    - Back on the lock screen exits.
    - The prompt opens by itself; "Unlock" retries after a cancel.
    - If the phone's screen lock was removed, app lock turns itself off and says so once.
  - Rules in `src/lib/appLock.ts` (unit tested): the timeout, the 5-minute system-screen grace, and the 10 s start window. The window exists because WhatsApp/SMS links and text share resolve before the app leaves the screen.
  - `runWithoutLock` wraps every system screen Hisaab opens:
    - camera and its permission dialog, photo picker, document picker;
    - file share sheet, text share, WhatsApp/SMS links;
    - Android settings, the notification permission dialog;
    - the unlock prompt itself.
  - Enabling needs a phone screen lock and one confirmation prompt.
  - Secure flag while lock is on: screenshots blocked, blank recents.
- **Onboarding (SET-08):** 3 steps (offline, back up, optional lock switch) → Get started. It is a gate, not a route. Existing installs see it once.
- **About (SET-07, SET-09):**
  - version, privacy promise, "Each phone has its own separate data";
  - **Open-source licences** (`/licenses`): 33 direct dependencies with their licence text, generated by `npm run licenses`; a test fails if the list is stale;
  - **Share diagnostic info**: share sheet, per the owner's decision. The report now includes the schema version and row counts, and a seeded-data test proves it has no amounts, names, phone numbers, or notes.
- **Polish:**
  - P8-1 fixed: icon boxes grow with the font scale, so glyphs are no longer clipped.
  - Receipt viewer got loading, error, and empty states (it was a blank black screen).
  - Shared `Toggle` with a visible thumb in both states and themes.
  - Licence text unwrapped so it fits the screen.
