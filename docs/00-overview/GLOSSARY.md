# Glossary

Status: Approved · Last updated: 2026-10-21

| Term | Meaning |
|---|---|
| **Paise** | Integer minor unit of INR. ₹1 = 100 paise. All stored money is paise. |
| **Transaction** | An income or expense entry. Only transactions count towards income, expense, cash flow, budgets, and category reports. |
| **Income** | Money the user earned or received that is *not* udhaar (salary, gift, refund, interest from a bank, etc.). |
| **Expense** | Money the user spent that is *not* udhaar. |
| **Recorded cash flow** | `income − expense` for a period, from the user's entries only. **Not** a bank balance. |
| **Category** | A label for a transaction. Each category is either income-type or expense-type. |
| **Payment method** | `cash`, `upi`, `bank_transfer`, `card`, `other`. |
| **Receipt / attachment** | An image attached to a transaction, stored inside the app. |
| **Udhaar** | Informal money between the user and a friend. Not income, not expense. |
| **Person** | A friend in the udhaar section. Name required; phone and notes optional. Not linked to phone contacts. |
| **Udhaar entry** | One movement of money with a person: **gave** (user gave money to the person) or **got** (user received money from the person). |
| **Gave** | Money left the user to the person — lending, or returning money the user had taken earlier. |
| **Got** | Money came to the user from the person — borrowing, or the person returning money. |
| **Balance (per person)** | `sum(gave) − sum(got)` for that person. |
| **You will get** | Balance > 0. The person owes the user. Shown in green with ↓ icon ("money coming to you"). |
| **You owe** | Balance < 0. The user owes the person. Shown in red/orange with ↑ icon. |
| **Settled** | Balance = 0. |
| **Return-by date** | Optional date per person by which the user expects the balance to be cleared. Used for overdue badges and reminders. |
| **Overdue** | Return-by date is before today and balance ≠ 0. |
| **Budget** | A monthly spending limit, either overall or for one expense category. Repeats every month. |
| **Backup file** | A `.hisaab` file containing all data and receipts, saved outside the app by the user. |
| **Restore** | Replacing all current data with the contents of a backup file. |
| **Future-dated** | A transaction whose date is after today. Listed, but excluded from totals until that date. |
