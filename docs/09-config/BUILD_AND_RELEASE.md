# Build and Release

Status: Approved (`Verify:` commands in Phase 2/11) · Last updated: 2026-10-21

Goal: a signed **release APK** for the owner (Phase 6 milestone) and friends (Phase 11), at ₹0.

## 1. Release keystore (one-time, most important step)

The keystore signs every release APK. **Android only installs an update over an existing app if both are signed with the same key.** Lose the key → friends must uninstall to install a new build → they lose their data unless they have a backup.

```powershell
# Run outside the project folder, e.g. in C:\Users\<you>\.hisaab-keys\
keytool -genkeypair -v -storetype PKCS12 -keystore hisaab-release.jks -alias hisaab -keyalg RSA -keysize 2048 -validity 10000
```

- Store passwords in a password manager (free options exist, e.g. Bitwarden free plan).
- Back up `hisaab-release.jks` in **two** separate places (e.g. a pendrive + personal Google Drive).
- Never put it in the project folder or git.
- Use this **same** key for local and EAS builds (don't let EAS generate a different one).

## 2. Build options

### Option A — Local build with Gradle (recommended: unlimited, offline, free)

1. Signing values in `%USERPROFILE%\.gradle\gradle.properties` (outside repo):
   ```
   HISAAB_STORE_FILE=C:\\Users\\<you>\\.hisaab-keys\\hisaab-release.jks
   HISAAB_STORE_PASSWORD=…
   HISAAB_KEY_ALIAS=hisaab
   HISAAB_KEY_PASSWORD=…
   ```
2. A small local config plugin `plugins/withReleaseSigning.js` adds a `release` signingConfig to `android/app/build.gradle` that reads those properties (needed because `android/` is regenerated by prebuild). `Verify:` current recommended approach in Expo docs.
3. Build:
   ```powershell
   $env:APP_VARIANT = 'release'
   npx expo prebuild --platform android --clean
   cd android; .\gradlew.bat assembleRelease; cd ..
   # Output: android\app\build\outputs\apk\release\app-release.apk
   ```
4. Rename to `hisaab-1.0.0-vc1.apk`.

**Smaller APK for phones (friends and owner):** build only the ARM CPU types real phones use. This roughly halves the size, which makes sharing on WhatsApp/Drive easier. It needs no new dependency:

```powershell
.\gradlew.bat assembleRelease -PreactNativeArchitectures=arm64-v8a,armeabi-v7a
```

That APK does **not** run on an x86_64 emulator. For the clean-emulator check in §3, build a separate universal APK (without the flag) and never distribute it. `Verify:` the flag name on the current React Native version, and record both APK sizes here after the first build.

### Option B — EAS Build Free plan (cloud)

- `eas.json` profile:
  ```json
  { "build": { "release-apk": {
      "android": { "buildType": "apk", "credentialsSource": "local" },
      "env": { "APP_VARIANT": "release" } } } }
  ```
- `credentials.json` (git-ignored) points to the same keystore.
- `eas build -p android --profile release-apk`
- `Verify:` Free plan monthly build limit and queue time. Never add payment details. Note: `eas build --local` is not supported on Windows (`Verify:`), so local builds use Option A.

## 3. Verify every release APK

- [ ] `versionCode` higher than the last distributed build.
- [ ] Signed with the release key: `apksigner verify --print-certs app.apk` → certificate SHA-256 matches the recorded fingerprint (write it in this doc after first build).
- [ ] Manifest permissions: `aapt dump permissions app.apk` (from build-tools) — no INTERNET, no unexpected permissions.
- [ ] `allowBackup=false` in merged manifest.
- [ ] Install on a clean emulator → launches → core flows work in airplane mode.
- [ ] Install **over** the previous APK on a phone with data → data intact.

Full checklist: [../10-testing/RELEASE_CHECKLIST.md](../10-testing/RELEASE_CHECKLIST.md).

## 4. Distribute to friends (free)

- Upload the APK to Google Drive → share link (or send as a WhatsApp **document**, or USB `adb install`).
- Send them the guide below.

### Friend install guide (send as text)

> **Hisaab install karne ka tarika**
> 1. Link se `hisaab-x.y.z.apk` download karo.
> 2. Open karo. Phone "unknown apps" ki permission maangega → us app (Drive/Files/Chrome) ke liye **Allow** karo.
> 3. Play Protect warning aaye toh **More details → Install anyway** (app Play Store se nahi hai isliye aata hai).
> 4. **Important:** Aapka data sirf aapke phone mein rehta hai. Mere ya kisi aur ke phone se koi connection nahi hai.
> 5. More → Backup se backup banakar Google Drive mein save karte raho. App uninstall kiya toh data chala jayega.
> 6. **Update:** naya APK aaye toh purana uninstall **mat** karo — seedha naya install karo, data safe rahega.

`Verify:` current Play Protect dialog wording.
